# Bug Reports and Observations

Only reproducible findings from live test execution belong in this directory.

A report must include:

- concise title;
- environment and timestamp;
- preconditions;
- exact reproduction steps;
- expected and actual result;
- severity with impact rationale;
- sanitized API/RPC evidence;
- Safe transaction and Ethereum transaction hashes when applicable;
- confirmation that no secret is present.

If behaviour is surprising but not proven to violate a requirement, label it as an
**observation**, not a bug.
